## Overview

Final Project is a complete game built in Godot 4 using GDScript. It was developed as a capstone — a chance to take a game concept all the way from idea to a polished, playable experience with real mechanics and a proper end state.

## My Role

Built everything: game design, programming, and asset integration. Godot's node-based scene system and GDScript made iteration fast, which was important for a project where design decisions needed to be tested quickly.

## Challenges

The challenge of any solo game project is scope management. A game that's fun to play requires more polish than it initially seems — enemy behavior that feels fair, controls that feel tight, a feedback loop that keeps the player engaged. I scoped to the smallest version of the concept that would still feel complete, then added depth from there.

GDScript's signal system was a good fit for the event-driven parts of the game — level transitions, UI updates, and enemy state changes all wired cleanly through signals without tight coupling between nodes.

## Outcome

A complete, playable Godot 4 game that demonstrates full-cycle game development: design, implementation, and enough polish to feel finished. Good foundation to build on for future game projects.
